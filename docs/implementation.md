# 开发决定 · 2026-10-23

依据 design-v1.1.md 与用户确认，直接在本地开发，无业务后端。

- 默认预算 35 元，可改或不限；报价有效期默认 5 分钟，可在设置调整。35 暂解释为预算，非有效期。
- 放宽预算从已核价基础池恢复；过期先核价，不自动绕过排除。
- 再转先移除上次结果；若存在其他主餐，盘面只保留其他主餐，再等权抽取。新一轮恢复临时排除。
- 统一反馈为“想换个肉”，点击后选择明确的鸡肉、牛肉、鱼肉；规则处理，不默认接 AI。
- 生成插画只用于装饰；真实食物图片优先用 MCP 返回的官方图片，缺图显示中性占位。
- 首先交付演示交互和 MCP 连接探测。没有 Token 与真实响应 schema，不编造餐品/价格映射；真实餐单适配待实测后完成。

实施顺序：核心状态测试 → 筛选/排除/重抽与报价模块 → 手机优先界面 → 真实 MCP 握手/工具发现诊断 → 本地验证。

验证重点：移除不补位、撤销不绕过条件、等权随机与角度一致、报价失效、旧请求隔离、MCP JSON/SSE、禁止写操作。

## 2026-10-23 浏览器接入验证

- localhost 来源直连官方 MCP 的预检返回 403，响应未允许该 Origin；真实浏览器检测也无法读取响应。
- 本机直接请求同一官方服务可返回 401，说明测试凭证被拒绝，但服务可达。
- 因此增加可选的本机薄代理 `/api/mcp`。固定官方上游、严格同源、仅监听 127.0.0.1、限制协议方法与只读工具、请求上限 256 KiB、不记录或保存 Token。
- 设置中新增“连接方式”与“检查连接环境（无需 Token）”。选择“本机中转（解决跨域）”后检查；返回 401 表示测试请求抵达官方服务，仍需个人 Token 完成真实握手及工具发现。
- 当前不能再仅以纯静态托管部署真实模式；真实模式如需上线，应部署对应同源代理，并重新确认部署安全与跨域行为。
