# 今天这顿，转一下

麦当劳单人餐转盘：预算筛选、移除/撤销、等概率抽取、换主餐、上一份、真实核价与复制餐单。

## 运行

需要 Node.js 22 或更新版本，无第三方依赖。运行 `npm start`，打开 http://127.0.0.1:5178 。默认展示明确标注的演示餐单。

真实模式：连接与设置 → 本机中转 → 输入个人 MCP Token → 搜索城市和地标 → 选择营业餐厅 → 加载真实餐盘。Token 默认仅在页面内存，断开或刷新后清除。

如需从本机文件读取凭证，可在 PowerShell 中设置后启动：

```powershell
$env:MCD_TOKEN_FILE = 'C:/your-private-folder/mcd-credential.txt'
npm start
```

页面将出现“使用本机凭证文件连接”。该凭证只在本机服务进程内存中，不传给浏览器，退出服务即清除。不要把凭证文件放进仓库，不要将此本地服务暴露到公网。

## 实现规则

- 默认预算 35 元，可调整或不限；报价有效期默认 5 分钟，可改。
- 每格为一份完整、核价成功的官方套餐，采用默认子项和默认特制配置。
- 首批最多 8 种不同主餐；手动移除不补位；放宽预算恢复基础池内候选。
- 再转先更新盘面，优先换肉类，再在可见格子中等概率抽取。
- 报价过期先更新；接受时始终重新核价；价格变化和超预算需再次确认。
- 排除需随单购买会员卡的套餐，不主动领券或使用个人券；采用核价接口确认的当前金额及优惠。
- 食品图片来自官方响应；AI 插画仅用于装饰。
- 不辣等条件只接受可核实标签，未知不当成满足。官方缺少不辣标签时可能没有候选。名称规则筛选不提供过敏安全保证。
- 份量分级、自由文本 AI、自主特制界面尚未开放；采用官方默认规格，可在官方购买时修改并核对价格。
- 只选餐、核价与复制餐单；不下单、不支付、不生成支付链接。

## 技术与测试

`dist/` 为前端，`server.mjs` 提供本地预览和可选薄代理。当前官方服务不允许本地网页跨域请求，真实模式使用 `/api/mcp` 同源中转：仅监听 127.0.0.1、固定官方上游、校验 Origin、限制协议和工具，不记录凭证或业务响应。公网部署需要另行部署安全的同源代理；仅静态托管无法保证真实模式可用。

```sh
npm test
node scripts/verify-live.mjs /path/to/private-credential.txt 南京 新街口
```

测试覆盖筛选、撤销、落点、默认套餐必选项、特制键、金额、图片域名、SSE、握手、浏览器 fetch 与代理限制。真实测试仅查询/核价；原始响应放在被 Git 忽略的 `.local/`，不上传账号数据。

已在南京营业门店验证：工具发现、菜单与子项、8 份完整套餐核价、接受后再次核价。测试价格不代表未来价格。
